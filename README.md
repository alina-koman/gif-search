# GIF Finder

Адаптивний застосунок для пошуку GIF через GIPHY API. Побудований на Angular 22, TypeScript і Tailwind CSS 4.

## Вимоги

- Node.js, сумісний з Angular 22: `^22.22.3`, `^24.15.0` або `^26.0.0`.
- npm.

## Налаштування GIPHY API

Створіть локальний файл середовища з прикладу:

```bash
cp src/environments/environment.example.ts src/environments/environment.ts
```

Вкажіть ключ у `giphyApiKey` у файлі `src/environments/environment.ts`. Локальний файл ігнорується Git. Не додавайте справжній ключ до `environment.example.ts` або інших файлів, що комітяться.

> Ключ, використаний у браузерному застосунку, можна побачити у зібраному JavaScript і мережевих запитах. Вважайте його публічним; за потреби обмежте ключ у налаштуваннях GIPHY. Для секретного ключа потрібен серверний проксі.

Angular CLI автоматично не читає `.env`; застосунок використовує TypeScript-файл середовища.

## Запуск

```bash
npm install
npm start
```

Відкрийте `http://localhost:4200/`.

## Можливості

- Пошук GIF із затримкою введення та станами завантаження, помилки й відсутності результатів.
- Адаптивні картки результатів і модальне вікно з деталями GIF.
- Копіювання посилання на сторінку GIF у GIPHY.
- Спроба завантажити GIF-файл із повідомленням про результат.

Застосунок показує до 20 GIF на пошук. Початкові тренди й пагінація («Завантажити ще») не реалізовані. Завантаження GIF може бути обмежене CORS на стороні хоста; у такому разі скористайтеся посиланням на GIPHY.

## Перевірки

Production-збірка:

```bash
npm run build
```

Unit-тести через Vitest:

```bash
npm test -- --watch=false
```

E2E-фреймворк у проєкті не налаштований.
