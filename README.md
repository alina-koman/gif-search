# GIF Finder

GIF Finder — адаптивний вебзастосунок для пошуку GIF-анімацій через [GIPHY API](https://developers.giphy.com/). Інтерфейс побудований на Angular 22, TypeScript і Tailwind CSS 4.

## Можливості

- Пошук GIF за ключовими словами з debounce 400 мс.
- Скасування попереднього запиту при новому пошуку, щоб застаріла відповідь не заміняла актуальні результати.
- Окремі стани початкового екрана, завантаження, помилки та відсутності результатів.
- Адаптивні картки GIF: 2 колонки на вузькому екрані, 3 на середньому та 4 на широкому.
- Кнопка **«Завантажити ще»** для посторінкового отримання результатів без втрати вже показаних GIF; помилку додаткового завантаження можна повторити.
- Детальний перегляд у центрованому діалоговому вікні: оригінальна анімація, автор (якщо наданий API), дата та рейтинг.
- Копіювання сторінкового посилання на GIPHY і спроба завантажити оригінальний GIF-файл.
- Клавіатурне керування діалогом: фокус переходить у вікно, Escape закриває його, фокус повертається до картки.

## Вимоги

- Node.js `24.15.0` або новіший у межах major-версії 24; рекомендована версія проєкту — `24.20.0` (див. `.nvmrc`).
- npm (версія, зазначена в `package.json`: npm 11).

Перевірте версії перед запуском:

```bash
node --version
npm --version
```

## Налаштування GIPHY API

1. Створіть API key у [GIPHY Developers](https://developers.giphy.com/).
2. У корені проєкту створіть локальний environment-файл із прикладу:

   ```bash
   cp src/environments/environment.example.ts src/environments/environment.ts
   ```

3. Відкрийте `src/environments/environment.ts` і замініть `YOUR_GIPHY_API_KEY_HERE` у полі `giphyApiKey` на свій ключ.

Файл `environment.ts` ігнорується Git. Зберігайте реальний ключ лише локально та не додавайте його до прикладу або комітів. Angular CLI автоматично не читає `.env`, тому застосунок використовує TypeScript-файл середовища.



## Встановлення та запуск

```bash
npm install
npm start
```

Після запуску відкрийте <http://localhost:4200/>. Angular dev server оновлює сторінку під час змін у вихідному коді.

Перед запуском і production-збіркою npm створює `src/environments/environment.ts` з прикладу, якщо локального файла ще немає. Уже наявний локальний файл не перезаписується. Для CI/CD, наприклад Vercel, можна задати змінну середовища `GIPHY_API_KEY`; ключ буде вбудований у клієнтський застосунок під час збірки та, як і будь-який ключ у frontend, буде видимий відвідувачам.

## Перевірки

Production-збірка:

```bash
npm run build
```

Артефакти збірки створюються в `dist/`.

Unit-тести через Vitest у одноразовому режимі:

```bash
npm test -- --watch=false
```

Тести покривають побудову GIPHY-запиту, валідацію параметрів, стани пошуку, debounce, застарілі відповіді, взаємодію з деталями, Clipboard API та помилки завантаження. E2E-фреймворк у проєкті не встановлений і не налаштований.

## Технічна структура

- `src/app/services/gif.ts` — HTTP-пошук у GIPHY та браузерні дії копіювання/завантаження.
- `src/app/models/gif.model.ts` — типи відповіді й GIF-даних.
- `src/app/components/search-bar/` — поле пошуку, очищення та debounce.
- `src/app/components/gif-grid/` і `gif-card/` — адаптивний список карток.
- `src/app/components/gif-detail-modal/` — доступний діалог із деталями та діями.
- `src/environments/environment.example.ts` — безпечний шаблон середовища; локальний `environment.ts` створюється окремо.

Tailwind CSS 4 підключений через `@tailwindcss/postcss` і `src/styles.css`.
